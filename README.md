# 🤖 Mini Chatbot

A simple rule-based chatbot built using Python. This project demonstrates basic Python programming concepts such as functions, loops, conditional statements, user input, string handling, and the datetime module.

## ✨ Features

- 👋 Interactive greetings
- 💬 Responds to basic conversations
- 🐍 Provides information about Python
- 🕐 Displays the current time
- 📅 Displays the current date
- 🧮 Simple calculator
- 😊 Responds to positive and negative messages
- 🚪 Exit using `bye`, `exit`, or `quit`

## 🛠️ Technologies Used

- Python 3
- VS Code
- Git
- GitHub
